你会感受到的变化

Agent 照旧在终端和 IDE 里忙碌。变的是你不再需要守在旁边。

以前

  • 离开电脑，Agent 卡在授权上，任务停住
  • 同时开着几个 Agent，不知道谁在等
  • 想看一眼进度，要切回终端
  • 把电脑交给 Agent，又怕它一路放行

现在

  • 手机收到提醒，随手批准，任务继续
  • 一个入口看清谁在跑、谁卡住、谁完成
  • 锁屏、后台、耳机里都能收到关键进展
  • 每一步放行都由你决定，超时自动交回终端

它如何做到

看见、抵达、决定。三件事，一件都不多。

01

看见

从进程、会话记录和 Agent hooks 三个层面观察，不要求 Agent 改造，也不改变它的运行方式。

02

抵达

关键事件按重要程度分级，只把真正需要你的那一刻送到你身边：手机推送、耳机语音、桌面菜单栏。

03

决定

手机上允许或拒绝，直接回答 Agent 的提问；戴着耳机时用口令确认；不方便时，超时自动交回本地终端。

三步开始

手机远程批准走桌面端。只想在终端里建卡、派单、看账本的话，装 CLI 就够了。

装桌面端

从发布产物下载安装，菜单栏出现 Mo Agent 图标，不占 Dock。

手机扫码配对

先扫第一个码安装手机 App，再扫第二个码完成配对。令牌 5 分钟有效、兑换即作废。

一键接入 Agent

菜单栏 →「一键配置 Agent…」，只写入 Mo Agent 自己的 hook，改动前自动备份。

只要 CLI

单文件二进制，不需要 Node。装在 ~/.local/bin/mo（Windows 为 %USERPROFILE%\.local\bin\mo.exe），负责终端侧的建卡、派单与账本。

# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/insky2005/mo-agent/main/installer/get-cli.sh | bash

# Windows（PowerShell）
powershell -ExecutionPolicy Bypass -c "irm https://raw.githubusercontent.com/insky2005/mo-agent/main/installer/get-cli.ps1 | iex"

隐私与安全

没有你的决定，它不会替你放行。这条写在设计里，也写在代码里。

  • 本机优先：只允许本机访问，且必须携带本机令牌。
  • 不自动放行：超时或无法确认，一律交回本地终端。
  • 语音有分寸：批准需复述口令，音频只在本机识别。
  • 改动可回退：只增删自己的 hook，改前自动备份。
  • 配对一次性：令牌 5 分钟有效，兑换即作废。
  • 来源可查：源码公开，可逐行审计。
