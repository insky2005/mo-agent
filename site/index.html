Mo Agent 是你电脑上的一位 AI Agent 小监理，叫 Momo，也叫“默默”。 它不替 Agent 干活，只在它需要授权、等待回答、完成或失败的那一刻，把消息递到你面前。

你会感受到的变化

Agent 照旧在终端和 IDE 里忙碌。变的是你不再需要守在旁边。

以前

  • 离开电脑，Agent 卡在授权上，任务停住
  • 同时开着几个 Agent，不知道谁在等
  • 想看一眼进度，要切回终端
  • 把电脑交给 Agent，又怕它一路放行

现在

  • 手机收到提醒，随手批准，任务继续
  • 一个入口看清谁在跑、谁卡住、谁完成
  • 锁屏、后台、耳机里都能收到关键进展
  • 每一步放行都由你决定，超时自动交回终端

它如何做到

看见、抵达、决定。三件事，一件都不多。

01

看见

从进程、会话记录和 Agent hooks 三个层面观察，不要求 Agent 改造，也不改变它的运行方式。

02

抵达

关键事件按重要程度分级，只把真正需要你的那一刻送到你身边：手机推送、耳机语音、桌面菜单栏。

03

决定

手机上允许或拒绝，直接回答 Agent 的提问；戴着耳机时用口令确认；不方便时，超时自动交回本地终端。

支持的 Agent

不同 Agent 的接入深度不同，能做到什么，这里写得明明白白。

Agent能力
Claude Code会话观察；手机批准 / 拒绝
Qoder CN桌面端与 IDE 会话观察；批准 / 拒绝；手机回答问题
WorkBuddy会话观察；批准 / 拒绝（放行仍在真机验证）
DeepSeek Harness会话观察；发送指令 / 中断
其他 Agent进程发现；可按模板继续接入

三步开始

先装 CLI，或者直接装桌面端。菜单栏常驻、不占 Dock，不打断你手头的事。

装桌面端

从发布产物安装，菜单栏会出现 Mo Agent 图标。

手机扫码配对

先扫第一个码安装手机 App，再扫第二个码完成配对。令牌 5 分钟有效、兑换即作废。

一键接入 Agent

菜单栏 →「一键配置 Agent…」，只写入 Mo Agent 自己的 hook，改动前自动备份。

# 只要 CLI（单文件二进制，不需要 Node）
curl -fsSL https://raw.githubusercontent.com/insky2005/mo-agent/main/installer/get-cli.sh | bash

隐私与安全

没有你的决定，它不会替你放行。这条写在设计里，也写在代码里。

  • 本机优先：管理页只允许电脑本机访问，并且必须携带本机令牌。
  • 不自动放行：超时或无法确认，一律交回本地终端。
  • 语音有分寸：批准需要复述口令，音频只在本机识别，不上传。
  • 改动可回退：只增删自己写入的 hook，修改前自动备份，坏 JSON 不覆盖。
  • 配对一次性：二维码令牌默认 5 分钟、兑换即失效。
  • 来源可查：source-available，全部代码在 GitHub 上公开可读。
